# FlowFTP logo concept v2 — Folded Route

A single route folds into an F. Its open blue endpoint represents a file reaching a remote workspace. This concept uses the same palette as v1 with a distinct monogram shape.

- `mark.svg` — standalone mark for light surfaces.
- `lockup.svg` — mark with FlowFTP wordmark for light surfaces.
- `app-icon.svg` / `app-icon.png` — dark macOS icon concept at 1024 × 1024.
- `brandkit-concept.png` — illustrative identity board, not a source asset.

Palette: charcoal `#111315`, blue `#2563EB`, cool white `#F6F7F8`. The wordmark uses the system's Inter, SF Pro Display, or Helvetica Neue font. The app's current icon has not been replaced.
