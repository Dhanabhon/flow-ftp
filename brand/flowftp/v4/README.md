# FlowFTP logo concept v4 — Shared Workspace

Two open corners represent local and remote file spaces forming one workspace. The center stays clear for the user's files. This geometric mark uses flat color and an open frame to give FlowFTP a direction distinct from the layered F and destination graphic in v3.

- `mark.svg` — standalone vector mark for light surfaces.
- `lockup.svg` — mark with FlowFTP wordmark for light surfaces.
- `app-icon.svg` / `app-icon.png` — dark macOS icon concept at 1024 × 1024.
- `brandkit-concept.png` — illustrative identity board, not a source asset.

Palette: navy `#203250`, blue `#2563EB`, dark charcoal `#111315`, cool white `#F6F7F8`; the dark icon uses `#60A5FA` for contrast. The wordmark uses the system's Inter, SF Pro Display, or Helvetica Neue font. The app's current icon has not been replaced.
