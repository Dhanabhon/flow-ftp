# FlowFTP logo concept v3 — Stream Portal

The blue F is a layered file path; its lower lane enters an open navy portal for the remote workspace. The light macOS icon and blue/navy contrast take visual cues from the supplied FlowClone reference, while the portal shape and mark are original to FlowFTP.

- `mark.svg` — standalone vector mark for light surfaces.
- `lockup.svg` — mark with FlowFTP wordmark for light surfaces.
- `app-icon.svg` / `app-icon.png` — light macOS icon concept at 1024 × 1024.
- `brandkit-concept.png` — illustrative identity board, not a source asset.

Palette: sky `#56BEFA`, blue `#1264EF`, navy `#203250`, cool white `#F9FBFD`. The wordmark uses the system's Inter, SF Pro Display, or Helvetica Neue font. The app's current icon has not been replaced.
