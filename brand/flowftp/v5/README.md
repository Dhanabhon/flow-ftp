# FlowFTP logo concept v5 — Tidal Flow

Three synchronized water waves express files moving continuously between local and remote workspaces. The waves share one rhythm: navy for the stable workspace, cobalt for active transfer, and sky blue for the next transfer state.

- `mark.svg` — standalone vector mark for light surfaces.
- `lockup.svg` — mark with FlowFTP wordmark for light surfaces.
- `app-icon.svg` / `app-icon.png` — dark macOS icon concept at 1024 × 1024.
- `brandkit-concept.png` — illustrative identity board, not a source asset.

Palette: deep navy `#203250`, cobalt `#2563EB`, sky `#72C7FA`, dark icon `#111B2D`, cool white `#F6F7F8`. The wordmark uses the system's Inter, SF Pro Display, or Helvetica Neue font. The app's current icon has not been replaced.
